How it works. Everything happens in your browser: nothing is uploaded, and the password is never stored — if you lose it, the archive cannot be recovered.

ZipCrypto is the original ZIP encryption, which is why Windows opens it with no extra software. It is weak: anyone holding part of a file's original content can recover the rest of that file without ever finding the password. Fine for keeping a document away from a casual reader, not for personal or commercially sensitive data.

AES-256 (WinZip AE-2: PBKDF2-HMAC-SHA1, 1000 iterations, 16-byte salt, HMAC-SHA1 authentication) has no such weakness, but the Windows Explorer extractor cannot read it — the recipient needs 7-Zip, WinRAR, Keka or similar.
